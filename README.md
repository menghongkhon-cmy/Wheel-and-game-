# 🎡 Wheel & Game Web Application

A responsive, interactive wheel-spinning web game built using pure vanilla front-end web technologies.

## 🌟 Overview
This project showcases pure front-end web development techniques, including DOM manipulation, CSS animations, and event handling without reliance on external heavy frameworks.

## ✨ Key Features
* 🎯 **Smooth Wheel Animation:** Customized CSS transitions and JavaScript logic.
* 📱 **Responsive Layout:** Works seamlessly across mobile phones, tablets, and desktop browsers.
* ⚡ **High Performance:** Lightweight vanilla JavaScript execution with zero dependencies.
* 🎨 **Interactive Design:** Clean UI components styled from scratch.

## 🛠️ Tech Stack
* **HTML5** – Semantic markup and page structure
* **CSS3** – Custom flexbox layout, animations, and visual styles
* **JavaScript (ES6+)** – Game state handling and user interaction logic
